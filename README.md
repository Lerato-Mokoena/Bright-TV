# 📺 Bright TV | Viewership Analytics Project

📌 1. Project Overview

The Bright TV Viewership Analytics Project focuses on analysing television viewership data to gain insights into audience behaviour, channel performance, viewing trends and audience engagement.

The purpose of this project is to transform raw data into meaningful business insights through data preparation, SQL analysis, data visualisation and interactive dashboard development.

The analysis explores audience engagement across television channels, viewing duration, geographical distribution and streaming patterns. The findings are used to identify trends, highlight opportunities and provide recommendations to support informed business decision-making.

📅 Reporting Period: 01 January 2016 – March 2016

🎯 2. Project Objectives

- Analyse television viewership and audience engagement.
- Identify the most popular television channels.
- Examine audience distribution across South African provinces.
- Evaluate viewing duration and streaming behaviour.
- Identify viewership trends and patterns over time.
- Develop interactive dashboards to present analytical findings.
- Generate actionable business insights and recommendations.

⚙️ 3. Project Methodology

The project followed a structured, end-to-end data analytics process.

📁 Step 1: Data Preparation – Microsoft Excel

- Imported and reviewed the original datasets.
- Cleaned and organised the data.
- Prepared datasets for further analysis.
- Used pivot tables and charts to explore initial viewership patterns.
- Conducted preliminary data analysis.

🗄️ Step 2: Data Analysis – Databricks

- Loaded the cleaned datasets into Databricks.
- Used SQL queries to analyse viewership data.
- Examined channel performance and viewing duration.
- Analysed audience distribution across provinces.
- Identified relevant trends and patterns within the datasets.

🎨 Step 3: Dashboard Design – Figma

- Planned the dashboard structure and layout.
- Developed visual design concepts.
- Organised dashboard elements to improve readability and usability.
- Established a consistent visual direction for the dashboards.

📊 Step 4: Dashboard Development – Power BI

- Developed interactive viewership dashboards.
- Presented key performance indicators (KPIs).
- Created visualisations to explore audience behaviour and viewing trends.
- Highlighted important findings and business insights.

📈 Step 5: Data Visualisation – Looker Studio

- Developed interactive viewership reports and dashboards.
- Presented key metrics and detailed visualisations.
- Incorporated filters to explore audience behaviour.
- Communicated analytical findings through clear visual reporting.

💻 Step 6: Dashboard Development – Lovable

- Developed an interactive dashboard concept.
- Designed a modern and user-friendly interface.
- Incorporated key metrics and business insights.
- Focused on dashboard presentation and user experience.

📝 Step 7: Documentation and Presentation – Canva and Microsoft PowerPoint

- Designed supporting project visuals and documentation.
- Created professional presentation materials.
- Presented key findings, business insights and recommendations.
- Used visual storytelling to communicate analytical results.

🔍 4. Key Areas of Analysis

The analysis focused on the following business areas:

- 📺 Channel Performance: Evaluating audience engagement and viewership across television channels.
- 📈 Viewership Trends: Identifying changes in audience activity over time.
- ⏱️ Viewing Duration: Analysing the average time viewers spend watching television.
- 🌍 Geographical Analysis:** Exploring audience distribution across South African provinces.
- 👥 Viewer Behaviour: Examining streaming patterns and audience engagement.

💡 5. Business Insights and Recommendations

The findings provide opportunities for Bright TV to:

- Identify channels attracting the highest audience engagement.
- Understand geographical differences in viewership.
- Identify peak viewing periods and audience activity patterns.
- Evaluate viewing duration to better understand audience engagement.
- Support content planning and programming decisions using audience trends.
- Improve business decision-making through data-driven insights.
